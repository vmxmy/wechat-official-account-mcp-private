EDITOR'S NOTE

系列导读

系列说明：这是「Codex 上车三部曲」的第一篇。三部曲的目标是带你从零装好环境——第一部装工具链，第二部用 CC Switch 配好 ziikoo 端点，第三部跑通第一次对话并在项目里执行 /init。全程不需要海外账号，一个 API Key 直连 GPT-5.6 Sol。

阅读提示：文中所有命令都单独放在代码块里，手机上长按代码块即可复制，粘到终端直接执行。

很多人卡在第一步：工具都没装对，后面的配置自然全错。这篇只做一件事——把三个工具装好、验证好，每一步都有检查点，装完你心里是有底的。

01

步骤 01 · 预计 2 分钟

准备 Node.js

先把两个命令行工具共同依赖的运行环境装好


Codex 和 Claude Code 都是 npm 包，Node.js 是必装前置，要求 18 以上版本。

STEPmacOS（推荐用 Homebrew）：
   bash

brew install node

Windows： 到 nodejs.org 下载 LTS 安装包，一路下一步即可。

装完验证（检查点 1）：

   bash

node -v

看到 v18 或更高版本号就算过关。

完成标志

✓ 终端显示 v18 或更高版本号，Node.js 环境准备完成。

国内加速小提示：如果 npm 下载慢，先把镜像源换成国内镜像，装完全局包可以再换回来：

   bash

npm config set registry https://registry.npmmirror.com

02

步骤 02 · 预计 2 分钟

安装 Codex CLI

让 codex 命令进入系统全局环境


   bash

npm install -g @openai/codex

macOS 用户也可以用 Homebrew：

   bash

brew install codex

装完验证（检查点 2）：

   bash

codex --version

能打印出版本号，说明 Codex CLI 已经在你的系统里了。注意：

完成标志

✓ 终端能够返回 Codex 版本号，安装步骤完成。

现在还打不开对话——它默认连 OpenAI 官方端点，需要登录 ChatGPT 账号。别急，第二部我们把它指到 ziikoo 端点上，就不需要官方账号了。

03

步骤 03 · 预计 2 分钟

安装 Claude Code

补齐 CC Switch 可统一管理的第二个命令行工具


   bash

npm install -g @anthropic-ai/claude-code

装完验证（检查点 3）：

   bash

claude --version

完成标志

✓ 终端能够返回 Claude Code 版本号。

为什么装它？两个原因：一是 CC Switch 同时管理 Claude Code 和 Codex 的供应商配置，装齐了以后切换成本最低；二是 CLI 工具这东西，早晚都要用第二个，不如一次装好。

04

步骤 04 · 预计 3 分钟

安装 CC Switch

用桌面应用统一管理不同工具的接口配置


CC Switch 是一个桌面应用（Tauri + Rust），专门干一件事：统一管理 Claude Code、Codex 等 AI CLI 的供应商配置，一键切换，不用手改任何配置文件。

安装方式：

  • 打开官网 ccswitch.io（或 GitHub 搜索 farion1231/cc-switch 进 Releases 页）
  • 按系统下载安装包：macOS 选 dmg（注意区分 Apple Silicon 和 Intel），Windows 选 MSI，Linux 选 AppImage
  • 正常安装并打开

装完验证（检查点 4）：打开 CC Switch，顶部能看到 Claude Code / Codex 等应用的标签页，说明它识别到了你刚装的 CLI 工具。

完成标志

✓ CC Switch 可以正常打开，并显示 Codex 与 Claude Code 标签页。

05

步骤 05 · 预计 1 分钟

完成工具链验收

逐项确认四个工具已经真正可用


到这里你应该有：

  • Node.js 18+，node -v 有版本号
  • Codex CLI，codex --version 有版本号
  • Claude Code，claude --version 有版本号
  • CC Switch 桌面应用，能正常打开

四样齐了，第一部任务完成。下一篇我们在 CC Switch 里添加 ziikoo 供应商：填入端点 api.ziikoo.com.cn、你的 token key 和 gpt-5.6-sol 模型，一次配置，永久生效。
