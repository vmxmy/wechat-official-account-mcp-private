EDITOR'S NOTE

系列导读

系列说明：这是「Codex 上车三部曲」的第二篇。上一篇我们装好了 CC Switch、Codex、Claude Code 三件套。这篇做整个上车站最关键的一步：把 ziikoo 端点（api.ziikoo.com.cn）、你的 token key 和 gpt-5.6-sol 模型配进 CC Switch，让 Codex 指向它。

先说清楚原理，后面排错才不慌：Codex 启动时读两个文件——~/.codex/config.toml（供应商和模型配置）和 ~/.codex/auth.json（密钥）。CC Switch 的作用就是替你正确地写这两个文件，并且在多个供应商之间一键切换。你手动改也能改，但改错一个字段就报半天错，交给工具最稳。

01

步骤 01 · 预计 1 分钟

准备接口信息

提前备齐接口地址、密钥和模型名称


  • 登录 ziikoo 控制台（地址：https://ai.ziikoo.com.cn）
  • 进入 API Keys / 密钥管理页面
  • 点击「创建密钥」，复制保存好——它形如 sk-xxxxxxxx，只完整显示一次

这个 key 就是你调用 gpt-5.6-sol 的全部凭证，不要提交到 git，也不要发给任何人。

02

步骤 02 · 预计 3 分钟

填写四项配置

在 CC Switch 中一次填完名称、地址、密钥和模型


  • 打开 CC Switch，切到 Codex 标签页
  • 点「添加供应商」，按下面填：
字段
填什么
名称
ziikoo（随便起，自己认得就行）
Base URL
https://api.ziikoo.com.cn/v1
API Key
上一步拿到的 sk-xxxxxxxx
模型
gpt-5.6-sol

Base URL 直接复制这行，注意带 /v1、末尾没有斜杠：

   text

https://api.ziikoo.com.cn/v1

模型名直接复制这行：

   text

gpt-5.6-sol

  • 保存后，在供应商列表里点 启用

如果表单里有「高级选项」，其中的上游格式保持 Responses 即可——ziikoo 端点原生支持 Responses 协议，直连不转换格式。

「启用」这个动作就是核心：CC Switch 会把这套配置写进 ~/.codex/config.toml 和 ~/.codex/auth.json。以后想换别的供应商，回来点一下切换就行，配置文件它替你管。

完成标志

✓ 供应商已经保存并启用，列表中显示「当前使用」。

STEP两个最容易踩的坑，提前说：
  • Base URL 必须带 `/v1`，末尾不能再加斜杠。写成 https://api.ziikoo.com.cn 或 https://api.ziikoo.com.cn/v1/ 都会报 404。
  • 模型名一个字符都不能错：gpt-5.6-sol，全小写，中间是连字符。

03

步骤 03 · 预计 2 分钟

检查本地配置文件

确认保存后的配置已经写入 Codex


如果你想知道 CC Switch 到底写了什么，打开 ~/.codex/config.toml，应该能看到类似这样的内容：

   toml

model = "gpt-5.6-sol"

model_provider = "ziikoo"

 

[model_providers.ziikoo]

name = "ziikoo"

base_url = "https://api.ziikoo.com.cn/v1"

wire_api = "responses"

wire_api = "responses" 这一行很关键：ziikoo 端点走的是 OpenAI Responses 协议（/v1/responses），这是 Codex 的原生协议，流式输出和工具调用的体验最完整。

再确认 ~/.codex/auth.json 里有你的 key（CC Switch 启用时已写入）：

   json

{

　"OPENAI_API_KEY": "sk-xxxxxxxx"

}

两个文件都对，配置就闭环了。

完成标志

✓ config.toml 与 auth.json 中的接口、模型和密钥保持一致。

04

步骤 04 · 预计 1 分钟

理解多工具切换

知道同一套方法如何扩展到 Claude Code


CC Switch 顶部切到 Claude Code 标签页，同样可以加供应商、一键切换。本篇聚焦 Codex，这里先不展开——等你 Codex 玩熟了，Claude Code 的配置是同一套逻辑，零学习成本。

05

步骤 05 · 预计 1 分钟

完成配置验收

按清单排除最常见的配置错误


  • CC Switch 的 Codex 供应商列表里，ziikoo 处于「启用」状态
  • ~/.codex/config.toml 里 base_url 带 /v1，wire_api 是 responses
  • ~/.codex/auth.json 里有你的 sk- key

三条都满足，硬件部分全部就绪。下一篇是见证时刻：启动 Codex 跑通第一句对话，然后在一个项目文件夹里执行 /init，让它给你的项目生成 AGENTS.md——从这篇开始，你就是真的“在车上”了。
