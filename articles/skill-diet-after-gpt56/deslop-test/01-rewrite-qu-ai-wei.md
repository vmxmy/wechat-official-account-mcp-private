# qu-ai-wei 改写（合成 AI 腔）

【门检】判断：AI 生成文本 | 证据：`随着…不断发展` 开场套路；`赋能/关键转折点/未来可期/希望这对您有帮助` 高频腔

【语体】自媒体 / 书面偏自媒体

GPT-5.6 发布后，模型更强了。  
社区里的口头禅也从「加 skill」翻成「删 skill」。

很多人第一反应还是装。  
更有效的是：扫 `~/.codex/skills` 和最近 session 日志，把 30 天没用的、功能重复的、只负责发现安装的项列出来。你确认后，再挪进隔离目录。

Skill 一多，Codex 会慢。  
约束一多，模型会「勤快地做错交付物」——每步都很认真，结果不是你要的。

Claude 跑 `/doctor`。  
Codex 把清理写成 Prompt。  
先报告，再动手。今晚别急着再装。

【打磨报告】
· 动词强化：多处 · 例：原文「赋能工作流」→ 终稿「清库存 / 挪进隔离目录」
· 节奏重塑：多处 · 长开场拆成短句
· filler 切除：多处 · 切词：随着…不断发展 / 此外 / 值得注意的是 / 综上所述 / 未来可期
· 抽象换具体(原文已有)：若干处 · 保留 GPT-5.6 / Skill / Claude / Codex，不编数字
· 语序归位：若干处
· 语体匹配档位：自媒体 / 书面

可观察指标：
- 具体名词：GPT-5.6、Skill、Codex、Claude、`/doctor`、session 日志
- 第一人称：1 处（「你确认后」第二人称为主）
- 引用原话：0
- 段长变异：短段为主
