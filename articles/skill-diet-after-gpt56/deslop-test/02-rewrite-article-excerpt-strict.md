很多人把 GPT-5.6 当成「更强的续杯」。  
拉开差距的，往往是另一件事：**你敢不敢做减法。**

下面这篇不推第三方清理工具。  
正文给出可直接粘贴的维护指令，并说明 Claude Code 与 Codex 的清理入口，以及推上反复出现的高赞观点。

---

## 二、为什么 5.6 之后更该清

社区有一句几乎成了口令：

> GPT-5.5：加 skill  
> GPT-5.6：删 skill  

不是段子。高强度用完 Sol 之后，很多人第一件事是 **gut skills**——砍掉野心过大的流程 Skill，把 AGENTS.md 删掉大半。  
因为约束太多，开始干扰模型；流程太重，强模型会「勤快地跑偏」。

最贵的 Token，经常花在 **错误交付物上的正确劳动** 上：  
每一步都很认真，交出来的却不是你要的东西。

## 六、收尾

GPT-5.6 不缺能力。  
它缺的是一个知道 **什么时候该让它停下来** 的使用者。

该外包给 Agent 的是执行。  
目标、品味，以及停的时机，别外包。
