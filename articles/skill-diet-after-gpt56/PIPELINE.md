# 内容生产流水线

```
选题研究
   ↓
【1】通用稿 00-universal.md   ← 唯一事实源
   ↓
   ├─【2a】公众号 01-wechat.md
   ├─【2b】推文   02-x-thread.md
   └─【2c】小红书 03-xiaohongshu.md
   ↓
飞书草稿区归档 → 发布 / 复盘
```

## 本文结构（强制）

1. **开头：可直接抄的 Prompt**（Codex 清理 + 自进化 + Claude /doctor）  
2. **去掉** 第三方 skill-diet 产品介绍  
3. **Claude cleanup vs Codex 自定义提示词** 对照  
4. **推上高赞观点与建议** 分条列出  
5. 清单 / CTA  

## 规则

1. 先通用稿，后分端；禁止先写一端再硬改另两端。  
2. 三端独立：结构、钩子、密度都不同。  
3. 飞书「草稿文档URL」默认挂通用稿。
