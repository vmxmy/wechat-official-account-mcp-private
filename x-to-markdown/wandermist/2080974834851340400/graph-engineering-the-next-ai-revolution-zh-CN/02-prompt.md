# Shared Translation Context

## Target
- Language: zh-CN (Simplified Chinese)
- Audience: general readers
- Style: technical — precise, concise, structured; light conversational opener OK
- Mode: normal

## Principles
- Rewrite into natural Chinese as if originally written in Chinese
- Facts, logic, and examples must match the source
- Prefer short, clear sentences over long Europeanized chains
- First occurrence of specialized terms: Chinese + (English) when helpful
- Preserve all markdown: headings, lists, bold, images, links
- Image paths: use `../imgs/...` (translation lives one directory deeper than source)
- Frontmatter: rename source fields with `source` prefix; keep cover image path adjusted
